My SDP 4 is code to control a prosthetic hand I have been working on over the past year. Right now the goal of the program is to control 8 servos individually and in a series allowing for motion within the prosthetic without over extending, retracting, or tangling the cord actuating the fingers.  When/if I have aditional time on this project I will code an interface with a mussle sensor (mioelectric sensor) that allows the arm to be contolled through diffrent mussle inputs.
